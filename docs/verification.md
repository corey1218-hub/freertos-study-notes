# 檢查紀錄

日期：2026-11-13

此檔只記錄實際執行的檢查。網站檢查與 FreeRTOS 韌體測試是不同範圍。

## 已完成

| 檢查 | 實際結果 |
| --- | --- |
| 第一次建置 | 2 篇筆記、4 個 HTML 頁面、61 個站內連結通過 |
| 加入 Timer 後建置 | 3 篇筆記、5 個 HTML 頁面、83 個站內連結通過 |
| JavaScript 語法 | `node --check assets/site.js` 通過 |
| 搜尋 `callback` | 只顯示 Timer 筆記，結果為 1 篇 |
| 搜尋無關文字 | 顯示 0 篇與空結果提示；清除後恢復 |
| Timer 分類 | 只顯示 Timer 筆記；切回全部恢復 3 篇 |
| Queue 填滿再傳送 | 放入 1～5，第六次傳送失敗，原本 5 筆保留 |
| Queue FIFO | 取出第一筆為 1，剩下 2、3、4、5 |
| Queue 重設及空時取出 | 重設為 0 筆，取出顯示接收失敗 |
| 文章目錄 | 點擊自我檢查，網址定位到 `#check` |
| 展開答案 | 點擊「看說明」後顯示原因與建議 |
| 程式碼複製 | 按鈕顯示已複製，剪貼簿包含 Timer 初始化片段 |
| 前後篇連結 | Timer 的上一篇可開啟 Queue；Queue 可見 Timer 下一篇 |
| AGENTS.md 下載 | 瀏覽器完成下載，下載檔案可讀取 |
| 桌機排版 | 實際開啟首頁與文章，未見重疊或截斷 |
| 窄螢幕排版 | 390px iframe（內容可用寬 375px）檢查首頁及文章；scrollWidth 與 clientWidth 均為 375px，沒有整頁橫向溢出；Queue 控制與程式碼區塊可見 |

建置器檢查的是欄位、允許的官方來源網址格式與站內連結；它不會自動判定外部文件內容是否正確，也不會把教學片段當成可執行韌體。
